# Ballot Basics 2026

A nonpartisan, mobile-friendly voter guide built for younger voters, made for an election-science project at Caltech.

The site has:

- a six-step checklist to get ready to vote, with progress saved in the browser
- plain-language cards on the offices that appear on a midterm ballot
- a summary of the three ways to vote
- a four-question quiz and a short glossary

It is one static `index.html` file with no server and no data collection.

## View it

Open `index.html` in a browser, or visit the GitHub Pages link once Pages is turned on for this repository.

## Sources

Rules differ by state, so the site points readers to official sources:

- [vote.gov](https://vote.gov)
- [U.S. Election Assistance Commission](https://www.eac.gov)
